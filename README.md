# 保卫双眼

一个纯前端的文本、表格和 JSON 搜索整理工具，可直接部署到 GitHub Pages。

页面统一使用宋体（设备未安装时回退到系统宋体类字体）。顶部「字号」提供 16、18、20、24、28、32 六档，调整粘贴文本、表格正文及 JSON 的阅读字号，并在当前浏览器记住选择。

记录、字段导航可分别收缩为序号窄栏，正文会用满剩余宽度。收缩时显示行序号或列序号，悬停可查看完整编号、标题或表头。导航列表单独滚动，顶部展开 / 收缩按钮保持可见。滚动正文时，左侧自动高亮正文顶部正在阅读的记录，并将序号滚入可见范围；字段导航同步切换到该记录，点击和搜索跳转仍优先保留目标位置。

表格每个字段正文左上角提供「复制」，复制完整纯文本并保留换行，不带字段名、按钮文字或搜索高亮样式。折叠时复制全文；编辑时复制当前内容，空字段会显示提示。

点击字段「修改」后，可选中部分文字，设置红、绿、蓝、橙、紫、深色，再点「保存」。颜色和文字一起保存在当前浏览器，刷新和搜索后仍保留。下载 Excel（.xlsx）会保留单元格内各段文字的颜色；Markdown 使用 HTML 颜色样式，需要阅读器支持。CSV、TXT、JSON 下载只包含文字，不包含颜色。

表格顶部的「表头筛选」可选择一列、输入该列要包含的文字，再点击「筛选」或按回车。英文不区分大小写，按字面包含匹配；输入过程中不改变结果。筛选后正文、记录导航、搜索范围一起更新，JSON 美化也保留筛选条件；点击「清除筛选」恢复。筛选只影响当前视图，原始数据和整表下载不变，重新打开文件时重置。

筛选条件支持「包含」「为空」「不为空」。后两种无需关键词；空单元格、缺失值及只有空格、制表符或换行的内容都算为空，0 和 false 算不为空。切换条件后点击「筛选」生效，清除筛选会恢复「包含」。

## 数据存储

- 用户导入、粘贴和编辑的数据只保存在当前电脑浏览器的 IndexedDB 或 localStorage 中。
- 网站不会把这些数据提交到 GitHub，也没有后端服务器。
- 不同电脑、不同浏览器或不同域名之间的数据不会自动同步。
- 清除该网站的浏览器数据会删除本地保存的内容。

## 本地使用

直接打开 `index.html` 即可。

## GitHub Pages

仓库发布为 GitHub Pages 后，使用 `https://<用户名>.github.io/<仓库名>/` 访问。
