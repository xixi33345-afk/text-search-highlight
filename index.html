📖操作说明

      
按表格导入文本，全局搜索并跳转高亮。所有操作都在本机完成，不联网。

    

    

      

        
1导入表格

        
    
          
  • 把 Excel / CSV / JSON 文件拖到页面任意位置，或点右上角「＋ 导入表格」选择文件。
    • 
          
  • 支持 .xlsx / .xlsm / .csv / .txt / .tsv / .json。旧版 .xls 请先在 Excel 里另存为 .xlsx。
    • 
          
  • 可以一次拖多个文件，会排队逐个确认。
    • 
        

        
表头、分隔符（Tab 或逗号）、文件编码（UTF-8 / GBK）、单元格里的换行和 Excel 日期都会自动识别，不用预处理。

        JSON 支持对象数组（每个对象一行）、单个对象（铺成「字段 / 值」两列）、同构对象字典（每个子对象一行），以及外层被包成 JSON 字符串的情形（会自动拆开）。嵌套的对象和数组会保留成 JSON 文本，不会丢内容。

      


      

        
2选择识别编号

        
    
          
  • 导入时会弹窗问用哪一列作为每条记录的编号，这个编号用在记录标题、左侧目录和限定下拉框里。
    • 
          
  • 列表按"像不像编号"排序，并显示样例值；有重复值或空值会标出来提醒。
    • 
          
  • 明显是编号的列（如 病案号、序号、sample_index）会自动选中；找不到就默认按顺序编号（#1、#2、#3…）。
    • 
          
  • 如果表格第一行不是表头，取消勾选「第一行是表头」，列名会变成"列1、列2…"。
    • 
        

      


      

        
3浏览：首页历史记录

        
    
          
  • 首页下方按文本粘贴、表格导入、JSON 美化分别显示历史记录。
    • 
          
  • 点历史记录可以重新打开；左上角「← 首页」返回。
    • 
          
  • 表格里的长内容默认折叠，可以用顶部的「展开 / 折叠」一次控制全部内容。
    • 
          
  • 在首页，顶部搜索框会按历史标题过滤。每条记录右侧可以删除（会二次确认）。
    • 
        

      

      

        
4搜索与跳转高亮

        
    
          
  • 在搜索框输入要找的字，所有命中即时变黄底，当前一个是橙底，并自动滚动到视图中部。
    • 
          
  • Enter 跳下一个，Shift+Enter 上一个，也可以点顶部的 ↑ ↓。右边的计数器显示"第几个 / 共几个"。
    • 
          
  • 折叠的长文本一旦命中会自动展开，不会出现"搜到了却看不见"。
    • 
          
  • 左侧第一列选择记录；表格文件还会显示第二列「字段导航」，点表头就会展开并跳到当前记录的对应内容。
    • 
          
  • 两列导航顶部的 ‹ 可以各自收缩成序号窄栏，正文随之变宽；记录栏显示第几条，字段栏显示第几列，鼠标停留可查看完整编号、标题或表头。再点 › 展开，收缩状态会自动保留。
    • 
          
  • 导航列表单独滚动，顶部的展开 / 收缩按钮始终可见。
    • 
          
  • 滚动正文时，左侧自动高亮正文顶部正在阅读的记录，并把对应序号保持在可见范围内；字段导航也会切换到这条记录。搜索命中时，记录和字段导航会一起选中正确位置。
    • 
          
  • 页面统一使用宋体。顶部「字号」提供 16、18、20、24、28、32 六档，粘贴文本、表格正文和 JSON 内容一起调整；浏览器会记住选择。
    • 
          
  • Aa 区分大小写，.* 用正则（写错时输入框会变红），仅命中只显示有命中的记录。
    • 
        

      


      

        
5只搜某一条记录

        
    
          
  • 两种方式：顶部下拉框选一条，或在记录标题栏点「只搜这条」。
    • 
          
  • 限定后计数器只统计这条内的命中，上一个/下一个也只在这条里循环，其他记录不产生高亮。
    • 
          
  • 限定生效时下拉框变蓝、目录该条加蓝色竖条、卡片加蓝色描边。点「✕ 取消限定」恢复全部。
    • 
          
  • 已限定时点目录里另一条就直接换成搜那一条，不用先取消。
    • 
        

      


      

        
6修改并保存文本

        
    
          
  • 鼠标移到某个字段，下方出现「修改」，点它就地编辑，换行会保留。
    • 
          
  • 点「保存」或按 Ctrl+Enter 保存；Esc 或「取消」放弃本次修改。
    • 
          
  • 改过的字段左边加绿色竖条并标「已修改」，卡片上也会累计显示改过多少处。
    • 
          
  • 改的如果是编号列，记录标题、目录、下拉框会跟着一起更新。
    • 
        

        
修改保存在浏览器里，不会写回原始 Excel 文件。换浏览器、换电脑或清理浏览数据后数据会消失，原始文件请自行留存。

      


      

        
7下载 / 格式转换

        
    
          
  • 在文件里点顶部「⬇ 下载」，菜单里有 5 种格式可选；按 Ctrl+S 直接导出 Excel。
    • 
          
  • 在表格历史记录右侧点「↓」，可以直接导出该文件的 Excel。
    • 
          
  • 不管选哪种格式，都保持原表的行列顺序和表头，你改过的地方已经写进去了。
    • 
        

        

          Excel（.xlsx）保留单元格内换行（自动换行 + 顶端对齐），列宽自适应；全部按文本格式写入，00123 不丢前导零，长数字不变科学计数法
          CSV（.csv）带 BOM，Excel 双击不乱码；含逗号、引号、换行的内容按标准转义
          JSON（.json）一行记录一个对象，键用表头，缩进 2 空格；空表头回落成「列N」
          纯文本（.txt）一条记录一段，用编号分隔，「字段：值」逐行列出；多行内容缩进两格，原样保留换行
          Markdown（.md）标准管道表格，换行转 <br>、竖线自动转义，粘到文档里直接渲染
        

        
文件名形如 原名_已修改_20260826_1530.xlsx，带时间戳不会覆盖原文件；没改过的不带「已修改」。三种文本格式都带 BOM，记事本打开不乱码。导出在本机完成，不上传。若某列原本是日期，导出后是当时读到的文本形式（如 2026-03-13 07:57:07）。

      


      

        
8转换任务：JSON / 表格 → JSON / TXT / Markdown

        
    
          
  • 首页 JSON 美化方块里直接粘贴并美化；点「工作台」也可以进入完整转换界面。
    • 
          
  • 表格模式会扫描所有单元格，只整理可解析的 JSON；输出保留原行号、识别编号、原列名、JSON 路径和值。
    • 
          
  • 表格历史右侧的「{}」用于批量转换；打开文件后点顶部「{} 美化 JSON」，会在当前页面右侧直接显示结果。
    • 
          
  • 记录中的 JSON 字段会出现「{} 美化 JSON」按钮，可在右栏切换查看不同字段；点击左侧其他记录时，右栏也会同步。
    • 
          
  • 拖动原始内容与 JSON 美化之间的竖向分隔线可以调整两侧宽度；双击分隔线恢复默认，宽度会自动保留。
    • 
          
  • 选目标格式：JSON 美化、纯文本、Markdown 表格、Markdown 列表。直接载入 JSON 时默认只美化排版，使用 4 个空格缩进，不改字段和值。
    • 
          
  • 就地编辑：右侧就是普通编辑框，可以随意改。改过之后状态会变成「已编辑（未下载）」提醒你。
    • 
          
  • 下载：点右上角「⬇ 下载结果」或按 Ctrl+S，下载的是你编辑后的内容，不是重新生成的。改过的文件名会带「_已编辑」。
    • 
          
  • 也可以点结果区右上角的「📋 复制」，一次复制全部纯文本结果。
    • 
        

        

          自动拆包用于转成 TXT / Markdown 或扫描表格；JSON 美化时自动关闭，字符串里的 JSON 保持字符串
          展开嵌套用于转成 TXT / Markdown 或扫描表格；JSON 美化时自动关闭，不会拍平成「路径 / 值」
          自动折行默认开启，长行会按窗口宽度换行；只影响显示，不改内容
        

        
「重新生成」「切换格式」「改选项」都会覆盖编辑内容，有未保存编辑时会先问你。搜索框在这里会在结果文本里查找并选中命中，Enter / F3 跳下一个。

      


      

        
9快捷键

        

          Ctrl+F聚焦搜索框
          Enter / F3下一个命中
          Shift+Enter上一个命中
          Esc清空搜索 / 关闭弹窗 / 放弃编辑
          Ctrl+Enter保存正在编辑的文本 / 工作台里重新生成
          Ctrl+S下载 Excel / 工作台里下载结果
          Ctrl+B收起 / 展开记录与字段导航
          Alt+←返回首页
          F1 / ?打开这份操作说明
        

      


      

        
10数据存在哪里

        
    
          
  • 导入的表格和修改都存在本机浏览器（IndexedDB，容量约 10 GB），刷新和重开都不丢。
    • 
          
  • 整个页面离线可用，数据不会上传到任何地方。
    • 
          
  • 右上角 🌙 / ☀ 切换深色浅色，选择会被记住。
